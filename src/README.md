## Part 5. Этап деплоя

1. Поднял вторую виртуальную машину Ubuntu Server.

    ![5_runner](/src/pictures/5_runner.png)

    ![5_deploy](/src/pictures/5_deploy.png)

2. На раннере сменил пользователя на gitlab-runner, сгенерировал ssh-ключ командой `ssh-keygen` и скопировал его на ВМ деплоя командой `ssh-copy-id ws11@192.168.31.135`. Проверил на второй ВМ, что копирование успешно с помощью `cat /home/ws11/.ssh/authorized_keys`. Для избежания проблем с правами доступа к папке usr/local/bin сменил права командой `chmod`.

3. Напиcал этап для CD, который «разворачивает» проект на другой виртуальной машине. Запускается этап вручную при условии выполнения предыдущих этапов.

    ![5_gl](/src/pictures/5_gl.png)

4. Написал bash-скрипт, который при помощи ssh и scp копирует файлы, полученные после сборки (артефакты), в директорию /usr/local/bin второй виртуальной машины. `scp "$file" "$DEPLOY_USER@$DEPLOY_HOST:/tmp/"` копирует файл во временную директорию /tmp/ на целевой машине, `ssh "$DEPLOY_USER@$DEPLOY_HOST" "mv /tmp/$(basename "$file") $DEPLOY_DIR && chmod +x $DEPLOY_DIR/$(basename "$file")"` подключается по SSH к целевой машине, перемещает файлы в папку usr/local/bin и делает файлы исполняемыми. В случае ошибки фейлится пайплайн.

    ![5_bash](/src/pictures/5_bash.png)

5. В результате получил готовые к работе приложения из проекта SimpleBashUtils (cat и grep).
